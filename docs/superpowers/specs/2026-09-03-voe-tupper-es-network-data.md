# VoeTupper: Rede confirmada do Espírito Santo

## Dados recebidos para o piloto

A camada estadual deve usar os seguintes vínculos confirmados:

1. Giseli Aguilar: Norte do estado
2. Adriana Junta: Noroeste
3. Ritheli Radis: Serra
4. Tatiana Madeira: Vitória
5. Adriana Maia: Vila Velha e sul do estado

Gerusa fica acima dessas Empresárias no desenho da Rede, identificada como Distrito.

## Correção de modelagem

A primeira especificação usava `Distrito Grande Vitória` como raiz do piloto. Como a rede informada inclui Norte, Noroeste e Sul do Espírito Santo, a interface não deve apresentar Grande Vitória como se fosse o contêiner geográfico dessas cinco Empresárias.

Para a UI do MVP, usar:

Espírito Santo

Gerusa, Distrito

Empresárias por região

Ritheli Radis, Serra

Líderes confirmadas da Serra

Revendedoras ou Consultoras vinculadas

## Regras de dados

- As cinco Empresárias e respectivas regiões podem aparecer em perfis e na árvore estadual.
- Apenas a Serra é aberta em detalhe neste piloto.
- Não inventar líderes, revendedoras, metas, faturamento ou rankings das outras quatro regiões.
- Dados detalhados das demais regiões só entram quando forem fornecidos ou confirmados.
- `Vitoriaware` pode permanecer como referência histórica ou operacional, mas não como nível da árvore.
